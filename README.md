# AI-Audit-Red-Flag-Dashboard

This repository contains **AuditGuard**, an AI-assisted audit red-flag detection
dashboard for general-ledger data. The Streamlit application lives in
[`auditguard`](./auditguard), with its setup and usage instructions in
[`auditguard/README.md`](./auditguard/README.md).

The repository also includes the project documentation and generated user
manuals in PDF format.
